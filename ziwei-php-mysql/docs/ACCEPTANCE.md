# 驗收 / 回歸測試清單

## A. 系統層

1. `scripts/start-windows.bat` 能啟動 Web + MySQL，瀏覽器打開 `http://localhost:8080`。
2. `/api.php?action=health` 回傳 `ok: true`。
3. Edge / Chrome 可安裝 PWA；安裝後以獨立視窗開啟。
4. 重啟 Docker 後命例仍存在。
5. 「備份」匯出 JSON；「匯入」合併 / 覆蓋均可還原。
6. MySQL 與 Web 預設只 bind 127.0.0.1。

## B. 基本排盤

1. 1990-06-15 10:00 男：12 宮完整、無 JavaScript error。
2. 14 主星總數至少 14，宮位有輔星 / 雜曜 / 神煞。
3. 廟旺利陷、本命祿權科忌可顯示。
4. 命宮 / 身宮、命主 / 身主、五行局、四柱、生肖、星座有值。
5. 博士十二神、將前十二神、歲前十二神、十二長生可顯示。
6. 大限與小限可見。
7. 點宮位後，本宮及三方四正高亮並畫連線。

## C. 運限

1. 任意指定運限日期與流時後：大限 / 小限 / 流年 / 流月 / 流日 / 流時同步更新。
2. 各運限四化（祿權科忌）與流曜顯示在正確宮位。
3. `decadalList()` 至少 10 個大限；每限 ageRange / yearRange 完整。
4. `yearlyList()` 每大限 10 個流年。
5. `monthlyList()`：普通年 12 項；遇閏月依 fixLeap 可為 13 / 14 項。
6. 23:00 出生：timeIndex 使用晚子時 12；dayDivide `current` / `forward` 結果需按設定切換。

## D. 必做的命理邊界回歸集

以下不能只靠「畫面看起來對」。正式商用前要用你指定門派的權威排盤逐筆比對：

1. 農曆閏月 1–15 日、16 日以後各至少一例。
2. 立春前後各至少一例（yearDivide normal / exact）。
3. 農曆正月初一前後各至少一例。
4. 生日當天前後（ageDivide normal / birthday）。
5. 大限切換前一天 / 當天 / 後一天。
6. 男女、陰年 / 陽年順逆各至少一例。
7. 早子時 00:xx、晚子時 23:xx。
8. 含閏月年份的流月切換。

每個權威命例至少比對：命身宮、五行局、14 主星、六吉六煞、四化、大限、小限、流年 / 流月 / 流日 / 流時。

## E. 命例資料

1. 新增、載入、修改、刪除。
2. 姓名搜尋。
3. 備註可保存超過一行文字。
4. `chart_json` 保存完整本命盤快照。
5. `engine_version` 固定為 2.6.1。
6. `settings_json` 保存該次算法設定，後續可追查為何同一生日曾排出不同結果。
